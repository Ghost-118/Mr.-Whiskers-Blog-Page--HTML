# Mr. Whiskers' Blog Page (HTML)

Proyecto de maqueta para un sitio web de blog personal utilizando exclusivamente **HTML5** semántico[cite: 9]. El objetivo principal es organizar de forma limpia el contenido mediante regiones clave de la página, como encabezados, menús de navegación, entradas de artículos independientes y datos de contacto[cite: 9].

---

## 🚀 Características

- **Estructura Semántica Completa:** Uso adecuado de etiquetas estructurales como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>`.
- **Elementos Multimedia y Figuras:** Implementación de la etiqueta `<figure>` y `<figcaption>` para agregar imágenes con pie de foto accesible.
- **Entradas Independientes:** Contenido organizado en etiquetas `<article>` para delimitar las distintas publicaciones del blog.
- **Información de Contacto Semántica:** Uso de la etiqueta `<address>` con enlaces directos a correo electrónico (`mailto:`) y teléfono (`tel:`).
